# CampusTrack

CampusTrack is a simple Java-based Student Result Management System.

## Features
- Student details and course selection
- Age and semester validation
- Five subject marks and grade calculation
- Attendance percentage and status
- Assignment score tracking
- Scholarship calculation
- Fee payment and balance calculation
- Semester clearance status
- Failed-condition reasons
- Performance recommendations
- Multiple student processing

## Technologies
- Java
- Scanner
- if-else
- switch
- while and do-while loops
- for loop
- break and continue
- Ternary operator
